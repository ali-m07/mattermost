Mattermost User Management

A practical guide to finding users and changing their activation status with a Personal Access Token.

Windows CMD macOS / Linux Bash Python

Choose your platform

Select one tab and follow the four steps. Every command uses PUT /api/v4/users/{user_id}/active; only the active value changes.

1

Configure and verify

Set your server address and Personal Access Token. The last command returns your own profile.

bash
export MM_URL="https://mattermost.example.com"
export MM_TOKEN="<your-personal-access-token>"
curl -s -H "Authorization: Bearer $MM_TOKEN" "$MM_URL/api/v4/users/me"
2

Find or list users

Look up a username to save its user id, or list active and deactivated users.

bash
USER_ID=$(curl -s -H "Authorization: Bearer $MM_TOKEN" \
  "$MM_URL/api/v4/users/username/<username>" | jq -r .id)

curl -s -H "Authorization: Bearer $MM_TOKEN" \
  "$MM_URL/api/v4/users?page=0&per_page=200&include_deleted=true"
3

Change account status

Use true to activate. Replace it with false to deactivate.

bash
curl -s -X PUT -H "Authorization: Bearer $MM_TOKEN" \
  -H "Content-Type: application/json" -d '{"active": true}' \
  "$MM_URL/api/v4/users/$USER_ID/active"
4

Verify the result

delete_at is 0 when the user is active. A non-zero timestamp means deactivated.

bash
curl -s -H "Authorization: Bearer $MM_TOKEN" \
  "$MM_URL/api/v4/users/$USER_ID" | jq .delete_at

1

Configure and verify

Install requests once, then keep the token outside your source code.

python
# python -m pip install requests
import os, requests

BASE = "https://mattermost.example.com/api/v4"
HEADERS = {"Authorization": f"Bearer {os.environ['MM_TOKEN']}"}
requests.get(f"{BASE}/users/me", headers=HEADERS).raise_for_status()
2

Find or list users

Read the user id from the lookup result, then optionally list all accounts.

python
user = requests.get(f"{BASE}/users/username/<username>", headers=HEADERS)
user.raise_for_status()
USER_ID = user.json()["id"]

users = requests.get(f"{BASE}/users", headers=HEADERS,
    params={"page": 0, "per_page": 200, "include_deleted": "true"})
print(users.json())
3

Change account status

Use True to activate. Replace it with False to deactivate.

python
response = requests.put(f"{BASE}/users/{USER_ID}/active", headers=HEADERS,
    json={"active": True})
response.raise_for_status()
4

Verify the result

delete_at is 0 when the user is active.

python
user = requests.get(f"{BASE}/users/{USER_ID}", headers=HEADERS)
user.raise_for_status()
print(user.json()["delete_at"])
Permissions

Your token needs user-management rights. Changing a System Admin normally requires full manage_system. LDAP/AD-managed accounts must be enabled or disabled in LDAP.

Common mistakes

There is no /deactive endpoint. A 401 means the token or header is invalid; a 403 means insufficient permission; a 404 usually means a wrong user id or route.
